# AI Todo App

A modern **AI-powered Todo application** built with Kotlin to help users create, organize, schedule, and complete tasks efficiently.

### Key Features

 **AI Assistant** – Generate, break down, and improve tasks using AI.
 **Task Management** – Create, update, delete, and complete tasks.
 **Calendar & Date Management** – Organize tasks by day and schedule them easily.
 **Smart Reminders & Alarm** – Get notifications with custom sounds when task time is reached.
 **Background Notifications** – Reminders work even when the app is closed or running in the background.
 **Offline Storage** – Store tasks locally using Room Database.
 **Task Progress** – Track completed and pending tasks.
 **Reactive UI** – Automatically update the UI using Kotlin Flow and Coroutines.

### Tech Stack

**Kotlin • Jetpack Compose • MVVM • Repository Pattern • Room Database • Coroutines • Flow • WorkManager • AlarmManager • Notifications • Retrofit/REST API • AI API • Dagger 2**

### Working Flow

**Create Task → Save to Room → Schedule Reminder → AI Assistance → Background Processing → Notification/Alarm → Complete Task → Track Progress**

### Project Goal

The goal was to build more than a basic CRUD Todo app by combining **AI, task scheduling, local persistence, background processing, notifications, and modern Android architecture** into one productivity application.
